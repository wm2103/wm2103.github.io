## 上一轮方案

用浏览器打开 `index.html` 查看三版总览，也可以直接双击下面任意 HTML 文件。不需要安装依赖或启动服务。

| 文件 | 设计方向 | 内容重心 |
| --- | --- | --- |
| `01-editorial.html` | 生长中的笔记：米白、深绿、杂志排版 | 笔记与项目平衡 |
| `02-lab.html` | 数字实验室：深色、明亮强调色、技术气质 | 项目与实践优先 |
| `03-minimal.html` | 留白手记：白色、文字、充足留白 | 阅读与笔记优先 |

每个页面顶部都有版本切换入口。总览页下方还可以展开交互预览，切换版本和手机显示宽度。

这是选定视觉方向用的首页原型。导航会跳转到对应内容，笔记与项目可以打开预览；文章弹窗展示原有笔记的摘要。项目示例是目前正在重构的博客本身。

三个页面的样式、脚本与插画均包含在各自 HTML 内，不需要在线字体、图片或第三方脚本。GitHub 链接需要网络。

`*-desktop.png` 和 `*-mobile.png` 是浏览器截图，总览页使用桌面截图作为缩略图。修改 HTML 后，应重新生成截图以更新缩略图。

当前阶段只制作设计预览；正式框架迁移将在选定设计后继续。
