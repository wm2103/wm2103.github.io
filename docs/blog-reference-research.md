# 个人博客设计参考

整理日期：2026-10-09。

用户反馈：上一轮三个 HTML 首页均不符合审美，先研究真实的高质量个人博客，再确定新方向。当前不继续基于旧原型推进框架迁移。

本地可视化入口：[真实博客参考集](../previews/references/index.html)。网页含实际首页截图及原站链接。

## 如何筛选

优先比较有真实长期内容的网站，覆盖中文图文博客、个人空间、技术写作与项目作品集。通过网页搜索找到候选与社区提及，再抓取原站内容和截图核对。这里的排序是设计参考优先级，没有核验访问量或流量排行榜，也不据此作热门程度排名。

## 参考站点

### 1. 张洪 Heo

原站：https://blog.zhheo.com/

- 类型：图文卡片 · 内容丰富。
- 实际观察：横向分类、精选大图、双列文章卡片和个人侧栏同时出现，首页一打开就有具体内容可看。
- 值得借鉴：重点看分类切换、文章封面的统一处理，以及「我的项目」如何和文章共处。
- 对本站的意义：适合你的笔记 + 项目双用途。精选位置可以展示项目，正文区域持续更新技术笔记。
- 取舍：需要一套统一的封面素材；栏目和侧栏可以按实际内容精简。
- 延伸页面：[看文章归档](https://blog.zhheo.com/archives/)。

### 2. 安知鱼 / 安和鱼

原站：https://blog.anheyu.com/

- 类型：模块化首页 · 中文博客。
- 实际观察：上方用多个大小不同的模块组合个人介绍、分类入口与推荐内容，下方承接文章卡片和个人资料。
- 值得借鉴：重点看顶部模块的尺寸关系、色彩分类，以及头像卡片与文章列表的呼应。
- 对本站的意义：适合想要完整、活泼、内容充实的中文个人博客。也容易安排独立的项目推荐区域。
- 取舍：它和 Heo 属于相近的卡片路线，可以选其中一套作为主要参考。
- 延伸页面：[主题与社区文档](https://docs.anheyu.com/)。

### 3. Innei

原站：https://innei.in/

- 类型：个人空间 · 文章与日常。
- 实际观察：首屏突出头像和个人介绍，下面有近期文章、日常片段和时间线。当前线上版本比传统文章列表更强调个人空间感。
- 值得借鉴：重点看导航组织、文章与短记录的区分，以及时间线对长期内容的组织方式。
- 对本站的意义：适合把学习、项目和日常都放进同一个网站，同时保留较轻的视觉感受。
- 取舍：当前首屏有较多留白和动效；是否采用这部分取决于你实际看原站后的偏好。
- 延伸页面：[当前设计项目 Yohaku](https://github.com/Innei/Yohaku)。

### 4. Josh W. Comeau

原站：https://www.joshwcomeau.com/

- 类型：技术写作 · 交互讲解。
- 实际观察：有辨识度的插画页头，加上清晰的文章摘要、分类和热门内容。文章中的交互示例是这个博客最值得体验的部分。
- 值得借鉴：重点看正文的字号、段落节奏、说明框、交互演示，以及读者如何从分类进入文章。
- 对本站的意义：很适合你的技术笔记；尤其是神经网络原理、代码过程这类需要解释和演示的内容。
- 取舍：整体插画是作者的个人形象。借鉴阅读与交互思路，视觉素材需要为你的站点另做。
- 延伸页面：[体验交互文章](https://www.joshwcomeau.com/css/interactive-guide-to-flexbox/)。

### 5. Brittany Chiang

原站：https://brittanychiang.com/

- 类型：个人作品集 · 项目展示。
- 实际观察：深蓝底色，左侧个人身份与章节导航，右侧组织介绍、经历和项目。它主要是个人作品集。
- 值得借鉴：重点看项目缩略图、简介、技术标签与链接如何组合，以及长页面的章节导航。
- 对本站的意义：适合作为独立「项目」页面的参考，让访客快速理解作品的内容与价值。
- 取舍：博客的文章浏览仍需要另做；项目展示结构可以单独采用，不必让全站变成简历。
- 延伸页面：[直接看项目区域](https://brittanychiang.com/#projects)。

### 6. Fomalhaut

原站：https://www.fomal.cc/

- 类型：沉浸背景 · 个性化博客。
- 实际观察：大幅背景图、个性化导航和丰富的兴趣入口，包含算法、计算机基础等学习笔记，也有音乐、画廊等个人内容。
- 值得借鉴：重点看背景氛围、内容分类和个人兴趣如何共存。动态效果请直接访问原站体验。
- 对本站的意义：适合你如果想要更鲜明、更有装饰感的个人博客，可作为与前几种路线的对照。
- 取舍：自动截图没有完整呈现动态背景；判断外观应以原站为准。重装饰也会增加性能和维护成本。
- 延伸页面：[看文章归档](https://www.fomal.cc/archives/)。

### 7. Anthony Fu

原站：https://antfu.me/

- 类型：开源开发者 · 项目索引。
- 实际观察：主页把个人介绍与真实项目直接连接起来，并把博客、项目、演讲、照片分成清晰入口。整体外观非常克制。
- 值得借鉴：重点看独立项目页，以及项目名称、简短说明和外链的整理方式。
- 对本站的意义：适合借鉴你未来多个开源项目的组织方式。它是补充性的结构参考。
- 取舍：你已经不喜欢上一轮的极简方案，所以暂不把这种外观当作默认方向。
- 延伸页面：[查看项目索引](https://antfu.me/projects)。

## 社区与推荐线索

- 安知鱼主题有公开项目与文档：[GitHub](https://github.com/anzhiyu-c/hexo-theme-anzhiyu)、[官方文档](https://docs.anheyu.com/)。它现在的博客域名页面显示「安和鱼」，个人卡片仍显示「安知鱼」。
- Innei 有公开的 [Shiro](https://github.com/Innei/Shiro) 与 [Yohaku](https://github.com/Innei/Yohaku) 项目。本次首页页脚显示 Yohaku，因此不把当前截图称为旧 Shiro 的准确样式。
- Heo 可在[博友圈收录页](https://www.boyouquan.com/blogs/blog.zhheo.com)查到独立博客记录，原站同时展示产品、设计、技术等真实栏目。
- Brittany Chiang 被 [Josh Comeau 的博客文章](https://www.joshwcomeau.com/blog/why-my-blog-is-closed-source/)评价为设计精良的作品集，并被多个开发者作品集参考列表收录。她的网站主要是作品集，应作为项目页参考。
- Josh 的原站首页提供文章与教程；[Flexbox 交互教程](https://www.joshwcomeau.com/css/interactive-guide-to-flexbox/)可用来具体体验讲解与交互的结合。
- Anthony Fu 的原站列出其 Vue/Vite 等开源参与经历与真实项目，用它参考项目组织比复刻极简外观更贴合当前需求。

## 下一轮应解决的问题

上一轮首页的大字标语、英文装饰和留白占比偏高，具体内容不足。这是本轮设计复盘，不能据此推断用户必然喜欢卡片或高密度布局。

用户随后选择了 **张洪 Heo 和安知鱼 / 安和鱼**。据此制作[新版 HTML 原型](../previews/04-cards.html)，采用安知鱼式模块化首屏、三色分类入口，结合 Heo 的精选内容、双列文章与个人侧栏。配色以浅灰蓝底、蓝紫重点卡片为主，封面与头像使用独立制作的 CSS / SVG 图形。

内容基于两篇原有学习笔记和当前博客重构项目；没有填充虚构文章、项目成果或访问量。交互覆盖分类、搜索、深浅色主题、摘要阅读与章节入口。当前仍为本地设计预览阶段。

网站布局与框架选择可以分开；引用某个 Hexo 博客作为视觉参考，不等于必须继续使用 Hexo。
